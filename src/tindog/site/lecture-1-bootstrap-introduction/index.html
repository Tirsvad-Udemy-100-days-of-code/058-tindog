Bootstrap introduction

Bootstrap is a CSS toolkit created at Twitter by Mark Otto and Jacob Thornton in 2010. Adding a few classes to ordinary HTML elements gives them a finished look.

Classes instead of CSS

One class, btn, turns a link into a button, and a second class picks its colour.

btn-primary btn-success btn-warning btn-danger btn-outline-dark

A card

A card groups a title, text and a button in a bordered box. It is copied from the documentation and adjusted.

The 12-column grid

Every row is split into 12 columns. A column spans some of them, and col-md-4 means "four of twelve from the medium breakpoint upwards, full width below it". Resize the window to watch the three boxes stack.

When to use it

Advantages

  • Fast to build with
  • Consistent styling
  • Works in all common browsers

Disadvantages

  • Many classes on each element
  • Heavy customisation is harder
  • Sites can look alike
