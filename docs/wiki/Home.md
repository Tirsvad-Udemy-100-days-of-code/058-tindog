# TinDog: Bootstrap on Day 58

Day 58 of Udemy's *100 Days of Code: The Complete Python Pro Bootcamp* teaches Bootstrap, a CSS toolkit built on a 12-column grid. This repository rebuilds the three lecture steps as static pages and serves them with a small Python 3.13 program that has no runtime dependencies.

## The lecture steps

| Step | Page | What we gained |
| --- | --- | --- |
| 1 | [Bootstrap introduction](Lecture-1-Bootstrap-Introduction) | What Bootstrap is, how a class turns plain HTML into a styled element, and how the 12-column grid works |
| 2 | [Bootstrap components](Lecture-2-Bootstrap-Components) | Ready-made components (navbar, card, carousel, footer) combined into the one-page site "Move It", plus dark mode |
| 3 | [TinDog landing page](Lecture-3-TinDog-Landing-Page) | A complete responsive landing page built section by section |
