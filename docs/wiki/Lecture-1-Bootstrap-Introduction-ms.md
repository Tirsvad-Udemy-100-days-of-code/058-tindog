# Langkah kuliah 1: Pengenalan Bootstrap

![Tangkapan skrin halaman pengenalan Bootstrap](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/058-tindog/raw/branch/main/docs/images/lecture-1-bootstrap-introduction.png)

## Apa yang ditunjukkan oleh langkah ini

Halaman ini menerangkan Bootstrap menggunakan Bootstrap sendiri: butang berwarna, satu kad dan demonstrasi grid 12 lajur.

## Apa yang kita peroleh

- **Bootstrap ialah satu set kelas CSS siap pakai.** Ia dicipta di Twitter oleh Mark Otto dan Jacob Thornton pada tahun 2010. Dengan menambah kelas seperti `btn btn-success`, elemen biasa digayakan tanpa menulis CSS.
- **Satu pautan CDN sudah memadai untuk bermula.** Helaian gaya dan berkas skrip dimuatkan daripada CDN; projek ini mengunci versi 5.3.3 dan menyemak fail dengan cincang integriti.
- **Grid mempunyai 12 lajur dan mengutamakan mudah alih.** `col-md-4` bermaksud empat daripada dua belas lajur dari titik henti sederhana ke atas, dan lebar penuh di bawahnya.
- **Komponen disalin dan diubah suai.** Kad diambil daripada dokumentasi dan diubah supaya sesuai.
- **Kebaikan dan keburukan.** Bootstrap pantas, konsisten dan berfungsi dalam semua pelayar biasa, tetapi elemen mengumpul banyak kelas dan penyesuaian besar-besaran lebih sukar.
