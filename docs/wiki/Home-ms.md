# TinDog: Bootstrap pada hari ke-58

Hari ke-58 dalam *100 Days of Code: The Complete Python Pro Bootcamp* daripada Udemy mengajar Bootstrap, satu alat CSS yang dibina di atas grid 12 lajur. Repositori ini membina semula tiga langkah kuliah sebagai halaman statik dan menyajikannya dengan atur cara Python 3.13 yang kecil tanpa kebergantungan semasa larian.

## Langkah kuliah

| Langkah | Halaman | Apa yang kita peroleh |
| --- | --- | --- |
| 1 | [Pengenalan Bootstrap](Lecture-1-Bootstrap-Introduction-ms) | Apa itu Bootstrap, bagaimana satu kelas menjadikan HTML biasa elemen yang digayakan, dan bagaimana grid 12 lajur berfungsi |
| 2 | [Komponen Bootstrap](Lecture-2-Bootstrap-Components-ms) | Komponen siap pakai (bar navigasi, kad, karusel, pengaki) digabungkan menjadi laman web satu halaman "Move It", serta mod gelap |
| 3 | [Halaman pendaratan TinDog](Lecture-3-TinDog-Landing-Page-ms) | Halaman pendaratan responsif yang lengkap, dibina bahagian demi bahagian |
